# Программа для деканата (ветка main)

## Постановка задачи
Дан массив студентов вида [ID, ФИО, Средний_балл]. Программа должна:
1. Найти Топ-3 студентов по среднему баллу.
2. Посчитать статистику: средний балл по группе, число двоечников (балл < 3).
3. Найти студента по ID рекурсивным бинарным поиском.

## Функции
- input_students — тестовые данные
- sort_by_score — сортировка по баллу (Bubble Sort)
- top3 — Топ-3 студента
- group_stats — статистика группы
- sort_by_id — сортировка по ID
- binary_search_by_id — рекурсивный поиск по ID
